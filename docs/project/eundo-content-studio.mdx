# Eundo Content Studio

WordPress 글을 준비하면서 주제 선정, 초안 작성, 이미지 제작, 저장 상태 확인을 반복했습니다. 이 과정을 하나의 콘솔로 묶었습니다. 결과는 곧바로 발행하지 않고 임시글로 남깁니다.

## 작업 흐름

**주제 추천 → 선택·제외 → 초안 생성 → 이미지 구성 → 임시글 검수**

### 다시 추천받고 싶지 않은 주제

추천 목록에서 필요 없는 주제를 제외하면 다음 추천에도 제외 상태가 유지됩니다. 단순한 화면 숨김이 아니라 서버에 저장하는 제외 목록입니다. 제목의 공백이나 추천 ID가 달라져도 같은 검색 의도인지 비교하고, 잘못 제외한 항목은 별도 목록에서 복원합니다.

완료된 주제와 사용자가 제외한 주제를 구분합니다. 제외를 취소했다고 이미 생성한 글까지 추천 목록에 되살리지 않도록 처리했습니다.

### 창을 닫아도 이어지는 생성

초기에는 로컬 대시보드와 Python 작업자가 붙어 있는 구조였습니다. 현재는 Netlify API, Supabase 작업 저장소, GitHub Actions 작업자를 연결하는 원격 실행 경로도 있습니다. 브라우저는 실행 주체가 아니라 작업 상태를 읽는 화면입니다.

배치 전체의 성공 여부만 남기지 않고 글마다 진행 상태와 결과를 저장합니다. 세 개 중 하나만 끝났다면 그 결과부터 확인하고, 실패한 항목은 다른 항목과 구분해 살펴볼 수 있습니다.

### 본문 이미지만 다시 만들기

내용이 괜찮은 임시글의 이미지가 아쉬울 때 글 전체를 재생성할 필요는 없습니다. 대표 이미지를 유지한 채 자동 생성된 본문 이미지 부분만 교체하는 경로를 추가했습니다.

| 변경 대상                  | 처리                    |
| -------------------------- | ----------------------- |
| 대표 이미지                | 기존 연결 보존          |
| 자동 생성된 본문 이미지    | 새 이미지로 교체        |
| 기존 WordPress 미디어 파일 | 삭제하지 않음           |
| 글 상태                    | 임시글 유지             |
| 이미 발행된 글             | 이 작업의 대상에서 제외 |

## 화면으로 보는 기능

**주제 추천**에서는 카테고리와 추천 비율을 고르고, 추천 목록과 제외 목록을 오갑니다. **생성 작업**에서는 글별 완료·진행·대기·실패 상태를 확인합니다. **콘텐츠 검수**에서는 임시글의 대표 이미지와 본문 이미지 수, 최근 재생성 성공 이력을 비교합니다.

갤러리의 데이터는 모두 샘플입니다. 특히 생성 진행률과 연결 상태는 화면을 재현하기 위한 응답이며, 실제 발행량이나 운영 가용성을 의미하지 않습니다.

## 구현 메모

작업 상태와 생성 결과를 분리해 저장하고, 같은 글의 이미지 재생성 이력을 추적합니다. 글·이미지 공급자 설정과 API 인증 정보는 서버에서 다룹니다. 브라우저에는 민감한 키 대신 연결 여부만 표시합니다.

글의 역할과 이미지의 역할도 나눴습니다. 썸네일과 본문 설명 이미지는 다른 구성과 비율을 쓰고, 본문은 주제에 맞는 구조로 작성합니다. 모든 글을 같은 카드 템플릿으로 찍어내는 방식은 피합니다.

## 공개 범위

실제 글, 운영 도메인, 계정 정보와 인증 키는 공개하지 않습니다. 이 페이지에는 구현 구조와 최신 화면만 남겼습니다.

## Next

긴 작업의 중단·재시도와 공급자 오류를 실제 운영 조건에서 더 확인할 예정입니다. 주제 제외와 저장 실패 검증을 통과한 것과 전체 발행 파이프라인의 운영 검증이 끝난 것은 별개입니다.
