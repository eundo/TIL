# Eundo Content Studio

`eundo-content-studio`는 WordPress 정보성 블로그 운영을 위해 만든 로컬 대시보드입니다. 주제를 고르고, 글과 이미지 패키지를 만들고, SEO/FAQ/광고 위치를 점검한 뒤 WordPress REST API로 draft 상태까지 넘기는 흐름을 한 화면에서 관리합니다.

## 구현 메모

- React 대시보드는 `topics`, `jobs`, `review`, `settings` 화면을 나눠 로컬 운영 콘솔처럼 사용합니다.
- Express 서버는 브라우저와 Python worker 사이에서 job 상태, draft 목록, 추천 작업 상태를 중계합니다.
- Python worker는 OpenAI Responses API, Gemini 이미지 생성, WordPress REST API, 이미지/HTML 패키징을 담당합니다.
- `.env`, `config.json`, `drafts`, `output`, 브라우저 프로필은 저장소에서 제외해 공개 범위를 분리했습니다.
- `PUBLISHING_STANDARDS.md`와 `VISUAL_GUIDELINES.md`로 글 문체, SEO, FAQ, 이미지 규칙을 코드 옆에 명시했습니다.

## 공개 범위

실제 draft 내용, 운영 도메인의 인증 정보, API key, WordPress 계정 정보는 공개하지 않습니다. 포트폴리오에는 로컬 대시보드 구조와 공개용 샘플 화면만 남깁니다.
