# Road Test 100

도로주행 시험을 세로형 3D 게임으로 옮긴 public 프로젝트입니다. 100점에서 시작해 신호, 차로, 속도, 보행자, 어린이보호구역, 방향지시등 위반을 감점으로 처리합니다.
