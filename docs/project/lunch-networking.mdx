# Lunch Networking

평일 점심시간을 짧은 직무 네트워킹 슬롯으로 바꾸는 실험입니다. 큰 커뮤니티보다 “오늘 점심에 만날 수 있는 사람”처럼 시간과 맥락이 좁은 연결에 초점을 맞췄습니다.

:::info
Repository는 private으로 운영 중입니다. 공개 페이지에는 제품 방향과 공개 가능한 구현 범위만 남깁니다.
:::
