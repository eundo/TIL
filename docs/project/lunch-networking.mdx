# Lunch Networking

다른 직무에서는 같은 문제를 어떻게 볼까. 멀리 약속을 잡기보다 평일 점심 한 시간으로 시작하는 네트워킹을 실험하고 있습니다.

## 범위를 좁힌 이유

일반적인 모임이나 데이팅 앱이 아니라 직무·업종 간 대화에 초점을 맞췄습니다. 한국 시간 평일 11:30~14:00 안에서 약 60분의 점심을 잡는 구상입니다. 시간과 지역이 맞는지, 어떤 일을 하는지, 무엇을 이야기할지가 추천의 기본 조건입니다.

## 화면으로 보는 기능

추천 목록은 직무·업종·지역·점심 시간으로 좁힙니다. 후보를 열면 프로필과 대화 주제를 확인합니다. 요청, 일정, 채팅, 내 프로필을 별도 화면으로 나누고, 수락 뒤에 대화를 시작하는 흐름을 구현했습니다.

캡처의 이름, 직장 유형과 거리는 저장소에 포함된 데모 데이터입니다. 실제 사용자 모집이나 매칭 결과가 아닙니다. 앱의 `서비스명 미정` 표시도 현재 개발 상태 그대로 남겼습니다.

## Recent Notes

기본 `main`에는 초기 MVP가 있고, 점심 네트워킹 방향의 후속 작업은 별도 작업 브랜치에 있습니다. **2026.08.09의 해당 브랜치**를 기준으로 화면과 설명을 갱신했습니다. 아직 main에 반영된 출시 기능으로 소개하지 않습니다.

## Next

서비스명, 운영 정책, 앱 등록 설정과 실제 인증 연동이 먼저입니다. 차단·신고와 취소·노쇼 정책도 실제 사용자 환경에서 확인해야 합니다. 필요한 출시 설정이 없을 때 배포 패키지 생성을 막는 검증이 있으며, 공개 운영 중인 서비스는 아닙니다.
