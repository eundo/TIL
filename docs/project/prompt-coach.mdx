# Prompt Coach

“업무일지와 주간 회고 템플릿, 자동화 스크립트를 만들고 싶어요.”

이 한 문장에는 세 개의 결과물이 들어 있습니다. 프롬프트 코치는 요청을 하나로 뭉개지 않고 각각의 산출물을 남긴 다음, 실행 환경처럼 빠진 조건을 묻습니다.

## 화면으로 보는 기능

### 1. 요청을 나누기

입력한 문장에서 분야와 의도, 필수 결과를 분류합니다. 소설·작문·이미지·업무·학습을 선택할 수 있지만 입력 내용이 선택 분야와 다르면 입력을 우선합니다. 현재는 규칙 기반 분석이므로 모든 문장을 정확히 이해하는 범용 AI로 소개하지 않습니다.

### 2. 부족한 조건만 묻기

갤러리의 예시는 업무 자동화 요청입니다. 사용할 도구와 적용 조건을 선택한 뒤 다음 질문으로 넘어갑니다. 답을 직접 쓰거나 모르는 질문을 건너뛸 수 있습니다. 질문은 최대 세 개로 제한합니다.

### 3. 원문을 보존한 결과

결과에는 원래 요청, 선택한 조건, 산출물과 확인 기준이 함께 들어갑니다. 필수 산출물이 빠졌는지 검사하고, 선택적으로 연결한 원격 결과가 기준을 통과하지 못하면 로컬 결과로 돌아가는 경로도 있습니다.

### 4. 저장한 뒤 다시 꺼내기

결과를 직접 편집하고 복사·공유할 수 있습니다. 저장은 이 기기의 최근 20개까지이며, 저장 직후 목록 또는 홈으로 이동할 수 있습니다. 계정 간 동기화는 없습니다.
