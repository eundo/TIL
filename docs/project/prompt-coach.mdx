# Prompt Coach

요청을 길게 꾸미는 도구가 아니라, 부족한 조건만 빠르게 물어보고 바로 쓸 수 있는 프롬프트로 정리하는 미니앱입니다. “뭘 만들지”보다 “어떤 결과가 나오면 좋은지”를 먼저 고정합니다.

:::info
Repository는 private으로 운영 중입니다. 공개 페이지에는 제품 방향과 공개 가능한 구현 범위만 남깁니다.
:::
