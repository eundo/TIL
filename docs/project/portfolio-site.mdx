# eundo.today

TIL 블로그에서 시작한 개인 포트폴리오입니다. Docusaurus에서 Astro로 이전했고, 글은 Markdown과 MDX로 관리합니다. 홈의 3D 화면과 프로젝트 갤러리는 React로 구현했으며 `main` 브랜치 push로 Netlify에 배포합니다.

## Astro 이전

- 프로젝트의 이름, 갱신일, 기술, 캡처를 MDX 메타데이터에 모으고 홈과 목록에서 함께 사용합니다.
- 글과 경력은 정적 HTML로 제공하고 3D, 갤러리, 방명록에 필요한 JavaScript만 불러옵니다.
- 기존 글 주소와 제목 링크를 유지하고, 목록 주소가 달라진 곳은 리디렉션합니다.
- 방명록과 방문자 통계는 기존 Netlify Functions와 Blobs 저장소를 사용합니다.
- 빌드할 때 내부 링크, 이미지, 제목 앵커, 이전 공개 주소와 프로젝트 목록 누락을 검사합니다.

## What It Does

- About, Stories, Projects, Notes의 역할을 분리합니다.
- Private repository는 코드 대신 실제 화면, 샘플 데이터, 구현 단위로 소개합니다.
- MDX로 프로젝트 상세 페이지를 계속 확장합니다.
- GitHub와 Netlify를 연결해 콘텐츠 수정 후 배포까지 같은 흐름으로 처리합니다.
