# eundo.today

TIL 블로그를 포트폴리오 중심으로 다시 정리한 Docusaurus 프로젝트입니다. 경력, 실무 회고, 개인 프로젝트, 학습 기록을 한 사이트에서 관리하고 `main` 브랜치 push로 Netlify에 배포합니다.

## Snapshot

| 구분 | 내용 |
| --- | --- |
| 상태 | Public portfolio site |
| 목적 | 경력, 실무 회고, 개인 프로젝트를 빠르게 훑을 수 있는 개인 사이트 |
| 접근 | 홈과 메뉴 구조를 포트폴리오 중심으로 재배치하고, 프로젝트는 실제 화면 중심으로 설명 |
| 기술 | Docusaurus, TypeScript, MDX, CSS Modules, Netlify |
| 배포 | `main` 브랜치 push 후 Netlify 자동 빌드 및 배포 |

## What It Does

- About, Stories, Projects, Notes의 역할을 분리합니다.
- Private repository는 코드 대신 실제 화면, 샘플 데이터, 구현 단위로 소개합니다.
- MDX로 프로젝트 상세 페이지를 계속 확장합니다.
- GitHub와 Netlify를 연결해 콘텐츠 수정 후 배포까지 같은 흐름으로 처리합니다.
