# Point Switch

보상형 광고를 본 뒤 포인트를 지급하는 흐름을 실험한 미니앱입니다. 화면의 재미보다 중요한 부분은 광고 완료, 지급 요청, 중복 지급 방지를 어디서 끊을지 정리한 점입니다.

:::info
Repository는 private으로 운영 중입니다. 공개 페이지에는 제품 방향과 공개 가능한 구현 범위만 남깁니다.
:::
