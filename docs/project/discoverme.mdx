# DiscoverMe

내 답을 고르는 것과 다른 사람의 답을 예상하는 것은 조금 다른 일입니다. 디스커버미는 하루 한 질문에 두 번 생각하게 만드는 작은 기록 앱입니다.

## 한 질문으로 시작하기

샘플 질문은 “친구와 의견이 다를 때, 나는 보통 어떻게 할까요?”입니다. 네 개의 선택지 중 `먼저 이유를 물어본다`를 고릅니다. 다음 화면에서 같은 답을 고를 사람의 비율을 예상합니다.

답을 선택하자마자 다른 사람의 분포를 보여주지 않는 이유는, 이미 보인 숫자에 내 답이 끌려가지 않게 하기 위해서입니다.

## 65%라고 생각했는데, 38%였다면

갤러리는 65%를 예상한 뒤 38%라는 결과를 받은 흐름입니다. 차이는 **27퍼센트포인트**로 보여줍니다. 맞고 틀린 사람을 가르기보다 내 예상과 다른 분포를 비교하는 장치입니다.

| 단계   | 화면에서 하는 일                  |
| ------ | --------------------------------- |
| 질문   | 내 선택 하나를 고름               |
| 추측   | 같은 답을 고를 비율 예상          |
| 결과   | 응답 분포와 예상 차이 확인        |
| 누적   | 주제별 기록과 연속 참여 상태 갱신 |
| 리포트 | 7일·30일 단위의 답을 요약         |

통계는 응답이 30개 이상 모였을 때 공개하는 조건이 있습니다. 캡처의 `100명`, `38%`, `7일`은 이 흐름을 보여주려고 만든 샘플이며 실제 이용자 수나 서비스 성과가 아닙니다.

## 쌓인 답을 다시 보기

첫 7개는 입문 질문이고, 이후에는 날짜별 공통 질문을 받는 구조입니다. 저장소에는 90개 질문과 10개 선택형 주간 미션이 준비돼 있습니다. 전체 질문 원문은 비공개로 유지합니다.

7일·30일 리포트는 답변을 규칙에 따라 정리합니다. 생성형 AI가 성격을 진단하는 기능이 아닙니다. 기록 지도는 주제별로 얼마나 답했는지 보여주고, 주간 미션에는 짧은 돌아보기 메모를 남길 수 있습니다.

## 현재 구현

React·TypeScript 화면과 Supabase Edge Function API를 나눴습니다. 참여 동의, 오늘의 질문, 답과 예측 저장, 분포, 기록 지도, 리포트, 데이터 삭제 경로가 있습니다.

이번에는 최신 프런트엔드에서 **질문 → 추측 → 분포 → 리포트 → 지도**를 실제로 조작했습니다. API 응답만 샘플로 대체했고, 운영 저장소에 답을 쓰거나 외부 모델을 호출하지 않았습니다.

## 아직 초기 버전

2026.09.02의 첫 커밋을 기준으로 소개합니다. 자동 테스트·CI가 갖춰진 단계는 아니며 실제 토스 인증, 앱 등록, 운영 정책, 광고와 출시 검증이 남아 있습니다. 데이터 삭제 코드가 있다는 사실만으로 운영 개인정보 보호 검증이 끝난 것으로 보지는 않습니다.
