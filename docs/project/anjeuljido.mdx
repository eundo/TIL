# Anjeuljido

같은 열차 안에서 곧 내릴 사람이 좌석 신호를 남기고, 앉고 싶은 사람이 그 신호를 참고하는 WebView 미니앱입니다. 핵심은 “좌석을 보장한다”가 아니라, 복잡한 지하철 안에서 작은 힌트를 부담 없이 주고받는 것입니다.

:::info
Repository는 private으로 운영 중입니다. 공개 페이지에는 제품 방향과 공개 가능한 구현 범위만 남깁니다.
:::
