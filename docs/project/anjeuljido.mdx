# Anjeuljido

지하철에서 곧 내릴 사람이 자기 좌석을 표시하면, 같은 열차 안의 사람이 참고하는 앱입니다. 자리를 예약하거나 확보해 주지는 않습니다. 짧게 유효한 하차 예정 신호를 주고받습니다.

## 화면으로 보는 기능

### 어디로 가는 열차인가

출발역과 도착역을 고르면 방향을 계산합니다. 현재 역은 직접 고르거나 위치로 후보를 찾을 수 있습니다. 위치만으로 열차를 확정하지 않고, 운행번호·행선지·현재와 다음 역을 사용자가 대조하게 했습니다. 후보 목록의 첫 열차를 자동 선택하지 않습니다.

차량에 적힌 차량번호와 서울시 운행번호는 다른 값입니다. 두 입력을 구분하고, 운행번호는 서버에서 다시 확인하는 경로를 둡니다. 짧게 모은 위치 표본은 후보를 찾는 데 사용하며 원시 좌표를 저장·전송하지 않는 구조입니다.

### 문 대신 좌석을 바로 고르기

이전에는 호차 다음에 문을 고르고 좌석을 골랐습니다. 최신 버전에서는 호차를 선택하면 차량 전체 28석이 나옵니다. 실제 앉은 자리를 누르면 가까운 문 번호를 자동으로 계산합니다.

5호선은 8량, 9호선은 6량 구성을 반영합니다. 갤러리의 차량 이미지는 대표 좌석 위치도이며 모든 실차의 구조를 검증한 도면은 아닙니다.

### 지나간 신호는 남기지 않기

신호 생성·수정·종료, 만료, 신고 흐름을 구현했습니다. 같은 열차와 호차의 신호를 확인하고, 이전 화면의 늦은 응답이 현재 선택을 덮지 않도록 요청 상태를 구분합니다.

## Recent Notes

**2026.09.07** 최신 커밋에서 문 선택 단계를 건너뛰는 직접 좌석 선택을 반영했습니다. 열차 진행 방향과 호차 표시 보정, 이전 요청 응답 처리, 신호 재시도 검증도 포함돼 있습니다.

2026.09.13에 **250개 테스트를 실행해 통과**했습니다. 좌석 선택 화면 흐름, 잘못된 열차 확인, 오래된 응답, 생성 재시도, 운영 정책 차단 조건을 검증합니다. 이는 로컬 자동 테스트 결과이며 실제 지하철·토스 기기 검증을 대체하지 않습니다.

## Next

운영용 공유 쓰기와 신고는 인증, 비밀값, 보관 기간, 실제 기기 확인을 마칠 때까지 차단하는 조건이 있습니다. 개발용 보상인 `쉼표`도 테스트 상태이며 실제 토스포인트가 아닙니다. 현장 검증과 운영 설정을 완료한 뒤 공개 범위를 넓힐 예정입니다.
